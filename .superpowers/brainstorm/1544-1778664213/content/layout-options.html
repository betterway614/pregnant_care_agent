当前 PregnantTools.vue 把 5 个大模块挤在一个长页面，手机端滚动过长。以下是 3 种重构方案。

重构方案对比

A

方案 A：拆分为多个子页面（推荐）

将 /tools 拆分为独立子页面，底部 tab 保留「工具」入口，点击后展示工具网格导航。

• /pregnant/tools → 工具网格（图标入口）
• /pregnant/tools/fetal-movement → 胎动计数器
• /pregnant/tools/health-record → 快速录入
• /pregnant/tools/health-trend → 健康趋势图表
• /pregnant/tools/mental-health → 心理筛查
优点 每个页面聚焦单一功能，手机体验好
缺点 路由增多，需要导航回退逻辑
B

方案 B：Tab 分组 + 首页快捷入口

保留 /tools 页面但用 el-tabs 分组，同时在首页添加常用工具快捷入口。

• Tab 1「记录」：胎动计数 + 快速录入
• Tab 2「趋势」：健康趋势图表
• Tab 3「筛查」：心理健康筛查
• 首页快捷入口：胎动计数一键进入
优点 改动最小，保持单页面结构
缺点 Tab 内容仍然较多，图表加载影响整体性能
C

方案 C：首页整合 + 工具下沉

将高频功能（胎动计数、快速录入）提升到首页，低频功能（趋势图表、心理筛查）留在 tools 页。

• /pregnant/home：+ 快速录入卡片 + 胎动快捷入口
• /pregnant/tools：趋势图表 + 心理筛查 + 胎动历史
优点 高频操作一步到位，符合使用习惯
缺点 首页变重，需要精心设计信息层级
