## 3. 资源与隐私对比

| 维度 | ☁️ 云端 DashScope | 🖥️ 本地 llama-server |
|------|-------------------|---------------------|
| 模型规格 | 云端集群 (多卡并行) | 单机 AMD GPU, Q8_0 量化 ~35GB |
| 显存占用 | N/A (云端弹性) | ~35GB VRAM |
| 网络依赖 | 必需 (数据上传至云端) | 完全离线 |
| 数据隐私 | 数据离开终端 | **数据不出本机** |

| 硬件成本 | 按调用计费 | 一次性硬件投入 |

## 4. 结论

1. **延迟**: 本地总延迟 34.43s vs 云端 24.26s，本地快 -42%
2. **吞吐量**: 本地 43.5 tok/s vs 云端 129.4 tok/s
3. **输出量**: 云端平均输出 3136 tokens，本地平均输出 1497 tokens (无限制，自然结束)
4. **隐私**: 本地部署实现数据完全不出端，满足医疗数据隐私合规要求
5. **可用性**: 本地部署支持离线使用，不依赖网络稳定性
6. **成本**: 本地部署为一次性硬件投入，无持续 API 调用费用
