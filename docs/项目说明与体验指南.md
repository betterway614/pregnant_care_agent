# AI-Care 孕期智能管理平台 - 项目说明与体验指南

## 一、项目简介

**AI-Care 孕期智能管理平台**是一个基于 AI 技术的孕期健康管理辅助系统，专为产科场景设计。平台通过孕妇端、护士端、医生端三个智能体的协同工作，实现孕期全程智能化管理。

> **声明**：本系统仅用于科研/教学辅助，不用于临床诊断与治疗决策。

### 核心特性
- **三端协同**：孕妇端（小安）、护士端（小护）、医生端（Dr.智）智能体协作
- **AI 对话**：基于大模型的智能问答与情绪安抚
- **高危预警**：FGR（胎儿生长受限）风险评估与预警
- **自动随访**：智能排期与自动随访数据采集

## 五、快速启动

### 5.1 启动后端

```bash
# 进入后端目录
cd backend

# 安装依赖（首次运行）
pip install -r requirements.txt

# 启动后端服务
python run.py
```

后端服务启动后运行在 `http://localhost:9999`

### 5.2 启动前端

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

前端服务启动后运行在 `http://localhost:3000`

### 5.3 局域网访问

如需局域网内其他设备访问，前端配置 `vite.config.ts` 已设置 `host: '0.0.0.0'`。

局域网访问地址：
- **前端**：`http://<你的IP>:3000`
- **后端 API**：`http://<你的IP>:9999`

## 七、体验指南

### 7.1 孕妇端体验

1. **登录**：访问 `http://localhost:3000`，输入孕妇卡号（如 `H202501`）和密码 `123456`

   - 尝试表达情绪："最近有点焦虑，睡不好"

3. **随访管理**：查看随访记录、审核随访结果
4. **排期管理**：为孕妇安排产检计划

### 7.3 医生端体验

## 十、配置说明

### 后端配置（backend/.env）

```env
# LLM 配置
LLM_MODE=mock                    # mock/cloud/local
LLM_API_KEY=your-api-key         # DeepSeek API Key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# FGR 配置
FGR_MODE=mock                    # mock/npu

# 数据库配置
DB_TYPE=sqlite                   # sqlite/postgres
DB_NAME=ai_care
```

### LLM 模式说明

| 模式 | 说明 |
|------|------|
| mock | 使用预设回复，无需 API Key |
| cloud | 调用云端 API（DeepSeek） |
| local | 使用本地 Ollama 模型 |

## 十一、常见问题

### Q1: 启动后无法访问？
- 确认后端和前端都已启动
- 检查端口是否被占用（9999、3000）
- 查看控制台是否有错误信息

### Q2: AI 对话无响应？
- 检查 `.env` 中的 LLM 配置
- 使用 `mock` 模式可无需 API Key
- 确认网络可访问 API 服务

### Q3: 局域网其他设备无法访问？
- 确认防火墙已放行端口 3000 和 9999
- 确认使用正确的局域网 IP 地址
