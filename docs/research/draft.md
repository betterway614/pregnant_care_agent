# 产科随访标准与随访模板设计调研报告

## 摘要

本报告基于中国《孕前和孕期保健指南》、《妊娠期高血糖诊治指南(2022)》、《妊娠期高血压疾病诊治指南(2020)》、FGR相关共识、EPDS量表规范，以及国际ACOG/NICE指南，梳理不同风险等级孕妇的随访标准，为结构化随访模板设计提供医学依据。

---

## 一、中国产前检查规范

### 1.1 产检时间节点（国家卫健委《孕前和孕期保健指南》）

| 孕周 | 检查频次 | 核心内容 |
|------|----------|----------|
| 6~13+6周 | 首次 | 建册、NT筛查、血常规、尿常规、血型、肝肾功能、空腹血糖、传染病筛查 |
| 14~19+6周 | 1次/4周 | 唐氏筛查/无创DNA、常规保健 |
| 20~24周 | 1次/4周 | 胎儿系统超声筛查（大排畸）、血常规、尿常规 |
| 25~28周 | 1次/4周 | OGTT（GDM筛查）、血常规、尿常规 |
| 29~32周 | 1次/2周 | 常规保健、评估胎儿发育 |
| 33~36周 | 1次/2周 | 胎心监护开始、评估胎位 |
| 37~41周 | 1次/周 | 胎心监护、评估分娩方式 |

### 1.2 随访频次标准

- **低风险孕妇**：孕28周前每4周1次，28-36周每2周1次，36周后每周1次
- **高危孕妇**：根据风险等级增加频次，可每1-2周1次

## 二、妊娠期糖尿病(GDM)随访标准

**依据**：《妊娠期高血糖诊治指南(2022)》（中华医学会妇产科学分会产科学组）

### 2.1 血糖监测方案

| 场景 | 监测频次 | 监测内容 |
|------|----------|----------|
| 新诊断/血糖控制不良/胰岛素治疗 | 每日7次 | 三餐前30min + 三餐后2h + 夜间24点 |
| 血糖控制稳定 | 每周1次大轮廓 | 空腹 + 三餐后2h |
| 不需胰岛素的GDM | 每周1次小轮廓 | 空腹 + 三餐后2h |

### 2.2 血糖控制目标

- 空腹或餐前血糖：≤5.3 mmol/L
- 餐后2h血糖：≤6.7 mmol/L
- HbA1c：每2-3个月监测1次，控制在<5.5%

### 2.3 GDM随访核心问题

1. 空腹血糖值（mmol/L）
2. 餐后2h血糖值（mmol/L）
3. 饮食控制执行情况
4. 有无低血糖症状（头晕、心慌、出汗）
5. 运动情况（类型、时长、频次）
6. 体重变化
7. 胎动情况
8. 胰岛素使用情况（如适用）

### 2.4 GDM并发症监测

- 妊娠期高血压：每次产检测血压
- 羊水过多：超声评估
- 酮症酸中毒(DKA)：出现恶心、呕吐、乏力时检测尿酮体
- 巨儿：超声评估胎儿体重

## 三、妊娠期高血压/子痫前期随访标准

**依据**：《妊娠期高血压疾病诊治指南(2020)》

### 3.1 诊断标准

| 分类 | 血压标准 | 附加条件 |
|------|----------|----------|
| 妊娠期高血压 | SBP≥140 和/或 DBP≥90 mmHg | 尿蛋白阴性 |
| 轻度子痫前期 | SBP≥140 和/或 DBP≥90 mmHg | 尿蛋白≥0.3g/24h |
| 重度子痫前期 | SBP≥160 和/或 DBP≥110 mmHg | 多脏器损害 |
| 慢性高血压并发子痫前期 | 原有高血压 | 孕20周后新出现蛋白尿 |

### 3.2 监测要求

- **血压监测**：每日早晚各1次，推荐家庭血压监测
- **尿蛋白**：每次产检查尿常规，可疑时查24h尿蛋白定量
- **预警信号**：头痛、眼花、上腹痛、水肿加重

### 3.3 高血压随访核心问题

1. 今日血压值（晨起/晚间，格式 SBP/DBP）
2. 有无头痛、眼花、上腹痛、恶心呕吐
3. 水肿程度变化（手、脚、面部）
4. 胎动情况
5. 降压药物使用情况
6. 体重变化（短期快速增加需警惕）
7. 尿量变化

### 3.4 子痫前期预警信号（必须筛查）

- 血压突然升高（尤其舒张压>90mmHg）
- 体重异常增加（1周增>1kg）
- 持续性头痛
- 视觉障碍（视力模糊、闪光）
- 上腹部或右上腹疼痛
- 恶心呕吐（排除早孕反应）
- 少尿（24h<400ml）

## 四、FGR(胎儿生长受限)高危随访标准

**依据**：中华医学会相关共识、RCOG指南

### 4.1 诊断标准

- 超声评估胎儿体重<相应孕周第10百分位数
- 胎儿腹围<第5百分位数
- 宫底高度低于相应孕周标准3cm以上

### 4.2 监测方案

| 监测项目 | 频次 | 说明 |
|----------|------|------|
| 胎动计数 | 每日 | 每天早中晚各数1小时，每小时≥3次 |
| 超声评估（胎儿大小） | 每2-3周 | 至少间隔3周复查以降低假阳性 |
| 脐动脉多普勒 | 每1-2周 | FGR最重要的监测方法 |
| 大脑中动脉多普勒 | 按需 | ≥32周时参考价值更大 |
| 胎心监护 | 每周 | ≥32周后 |
| 生物物理评分 | 按需 | 综合评估 |

### 4.3 FGR随访核心问题

1. 近24h胎动情况（次数、规律性）
2. 体重变化
3. 有无腹痛、阴道出血
4. 饮食和营养摄入情况
5. 最近B超结果（如有）
6. 是否按时产检
7. 左侧卧位休息执行情况

### 4.4 紧急就医指征

- 胎动明显减少或消失
- 阴道出血
- 持续性腹痛
- 血压升高伴头痛

## 五、孕期心理健康筛查(EPDS)标准

**依据**：爱丁堡产后抑郁量表(EPDS)中文版、围产期心理健康管理指南

### 5.1 EPDS量表简介

- 10个条目，每项0-3分，总分0-30分
- 评估过去7天的情绪状态
- 建议在孕早期、孕晚期、产后6周各筛查1次

### 5.2 评分标准

| 分数段 | 风险等级 | 处理建议 |
|--------|----------|----------|
| 0-9分 | 正常 | 常规保健 |
| 10-11分 | 临界 | 加强监测，提供心理支持 |
| 12-15分 | 轻度抑郁 | 心理咨询，密切随访 |
| 16-19分 | 中度抑郁 | 心理治疗或药物治疗 |
| ≥20分 | 重度抑郁 | 药物+心理治疗，加强监护 |
| ≥30分 | 严重抑郁 | 立即转诊精神科 |

### 5.3 流行病学数据

- 中国围产期调查显示：轻度产前抑郁风险(EPDS>9)患病率约25.8%
- 每4名孕妇中约1人受抑郁困扰

### 5.4 心理健康随访核心问题

1. 最近心情怎么样？有无焦虑或低落？
2. 睡眠质量如何？每晚睡几个小时？
3. 食欲有无变化？
4. 身边有人陪伴和支持吗？
5. 最近最大的压力或困扰是什么？
6. 有无伤害自己的想法？（必须筛查）
7. 能否正常进行日常活动？

### 5.5 危机干预指征

- EPDS第10题（自伤想法）得分≥2
- 表达自杀意念
- 严重功能损害
- 需立即转介专业心理危机干预

## 六、孕早期/孕晚期特殊随访

### 6.1 孕早期（≤12周）特殊关注

| 关注点 | 说明 |
|--------|------|
| 早孕反应 | 恶心呕吐程度、能否正常进食 |
| 阴道出血 | 有无出血或褐色分泌物（先兆流产） |
| 叶酸补充 | 是否规律补充0.4-0.8mg/天 |
| 致畸因素 | 用药史、接触史（放射线、感染） |
| NT检查 | 11-13+6周 |

### 6.2 孕晚期（≥36周）特殊关注

| 关注点 | 说明 |
|--------|------|
| 临产征兆 | 见红、破水、规律宫缩 |
| 胎动 | 每日计数，每小时≥3次 |
| 胎位 | 胎先露、胎方位 |
| 宫缩 | 有无宫缩、频率、强度 |
| 分娩准备 | 待产包、分娩计划、母乳喂养准备 |
| 血压 | 筛查子痫前期 |
| 体重 | 监测增长速度 |

## 七、国际指南对照

### 7.1 ACOG（美国妇产科医师学会）

- **低风险**：孕4-28周每4周1次，28-36周每2周1次，36周后每周1次
- **总产检次数**：约10-15次
- **特点**：强调个体化，允许减少低风险孕妇产检次数（有证据支持≥10次产检不改善低风险妊娠结局）

### 7.2 NICE（英国国家卫生与临床优化研究所）

- **低风险**：初产妇约10次，经产妇约7次
- **特点**：减少不必要的产检次数，强调孕妇自我监测

### 7.3 对本项目的启示

- 随访频次应根据风险等级动态调整
- 低风险孕妇可适当减少随访频次，高危孕妇需加密
- 鼓励孕妇自我监测（胎动、血压、血糖、体重）

## 八、结构化随访数据标准

### 8.1 必须量化的指标

| 指标 | 数据类型 | 单位 | 采集频次 |
|------|----------|------|----------|
| 体重 | number | kg | 每次随访 |
| 血压(SBP/DBP) | text | mmHg | 每次随访/每日（高危） |
| 空腹血糖 | number | mmol/L | GDM每日/每周 |
| 餐后2h血糖 | number | mmol/L | GDM每日/每周 |
| 胎动次数 | number | 次/小时 | 每日 |
| 睡眠时长 | number | 小时 | 每次随访 |
| HbA1c | number | % | 每2-3月（GDM） |

### 8.2 定性记录的指标

| 指标 | 说明 |
|------|------|
| 主诉/身体感受 | 自由文本 |
| 恶心呕吐程度 | 轻/中/重 |
| 水肿程度 | 无/轻/中/重 |
| 头痛/眼花 | 有/无，描述 |
| 饮食情况 | 描述 |
| 用药依从性 | 是/否/部分 |
| 情绪状态 | 描述 |
| 运动情况 | 类型、时长 |

### 8.3 危机筛查字段（必须包含）

| 字段 | 说明 |
|------|------|
| 自伤想法 | EPDS第10题 |
| 阴道出血 | 有/无 |
| 胎动消失 | 有/无 |
| 剧烈腹痛 | 有/无 |
| 破水 | 有/无 |
| 严重头痛+视觉障碍 | 子痫前期预警 |

## 九、随访模板设计建议

### 9.0 数据边界（重要）

随访分为两个场景，数据来源不同：

| 场景 | 角色 | 可收集的数据 | 说明 |
|------|------|-------------|------|
| **线上随访（小安）** | 孕妇自述 | 体重、血压、血糖、胎动、睡眠、饮食、症状感受 | 仅限孕妇可自测的数据 |
| **线下评估（护士/医生端）** | 医护人员 | B超、血常规、尿常规、胎心监护、宫高腹围等 | 可有mock数据支撑 |

**设计原则**：随访模板中的问题必须是孕妇可以在线上自行回答的，不涉及需要专业设备或检查的数据。

### 9.1 模板设计原则

1. **场景化**：按风险等级和孕周选择模板
2. **结构化**：问题类型明确（text/number/select），便于数据提取
3. **可量化**：关键指标（血糖、血压、体重、胎动）必须支持自动提取入库
4. **安全筛查**：每个模板必须包含紧急情况筛查问题
5. **个性化**：根据风险标签动态插入相关问题
6. **渐进式**：先问一般感受，再问具体指标，最后筛查危险信号
7. **线上可达**：所有问题必须是孕妇可自测/自感的数据，不涉及专业检查

### 模板选择逻辑

```
if 孕周 < 12:
    template = "early_pregnancy"
elif 孕周 >= 36:
    template = "late_pregnancy"
elif "GDM" in risk_tags:
    template = "gdm"
elif "高血压" in risk_tags:
    template = "hypertension"
elif "FGR高危" in risk_tags:
    template = "fgr_high_risk"
elif EPDS >= 10 or "心理健康" in risk_tags:
    template = "mental_health"
else:
    template = "standard"
```
