# 基于AMD锐龙AI Max+平台的FGR适配多功能医疗智能体 项目汇总文档
## 一、项目基本信息
- **赛事**：第二十一届中国研究生电子设计竞赛（AMD命题）
- **命题方向**：基于AMD锐龙AI MAX+平台的端侧AI智能体与垂直行业创新应用
- **行业领域**：医疗健康管理（产科辅助，**仅限科研/教学辅助，不用于临床诊断与治疗决策**）
- **作品名称**：基于AMD锐龙AI Max+平台的通AI-Care孕期智能管理平台

## 二、核心设计思路
开发一套“AI-Care孕期智能管理平台”，通过孕妇端、护士端、医生端三个智能体的协同工作，实现：
- 对孕妇的全程无感随访与高情商陪伴，降低焦虑。
- 减少护士手工排期、随访、撰写记录的事务性工作。
- 为医生提供基于FGR算法的高危预警看板与循证医嘱辅助，提升诊疗质量与效率。

## 三、官方指定硬件配置（项目强制使用）
- CPU：AMD 锐龙 AI Max+ 395
- GPU：集成 Radeon 8060S GPU
- NPU：锐龙AI专用NPU
- 内存：128GB
- 存储：2TB SSD
- 统一内存架构（UMA）：最高96GB显存
- 开发环境：AMD提供云端开发环境

## 四、硬件分工（赛题强制要求：必须使用NPU/GPU）
1. **GPU**：通用医疗大模型推理、向量数据库检索、高吞吐医疗数据处理
2. **NPU**：自研FGR评估算法推理、指标计算、轻量医疗数据预处理
3. **CPU**：智能体任务调度、前后端交互、流程控制、报告生成
4. **统一内存**：大模型与FGR算法同机加载，无显存切换开销

## 五、核心功能
1. **通用医疗能力**：医嘱生成、医疗咨询、文书撰写、健康管理、随访提醒
2. **FGR专科能力**：产科超声指标解析、FGR风险评估、辅助报告生成
3. **智能体能力**：意图理解、任务规划、工具调用、多步推理、端到端输出

## 六、赛题合规要求（医疗赛道必满足）
1. **本地推理优先**：核心模型与FGR算法均在本地AMD平台完成，不依赖云端推理
2. **隐私安全**：医疗数据本地存储、脱敏处理、访问控制、加密保护
3. **合规声明**：仅用于科研教学辅助，**不替代临床诊断、不提供治疗决策**
4. **端到端闭环**：用户输入→模型推理→工具调用→结果输出→可视化反馈完整流程

## 五、技术栈（官方推荐）
- 系统：Windows/Linux
- 框架：PyTorch、TensorFlow、ONNX Runtime
- AMD加速：Ryzen AI SDK（NPU）、ROCm（GPU）
- 推理引擎：Ollama/LM Studio/llama.cpp/VLLM
- 优化方案：INT4/INT8量化、模型蒸馏、剪枝

## 六、评分亮点（贴合评分标准）
1. **技术创新**：通用医疗大模型+专科FGR工具，CPU+GPU+NPU异构协同
2. **行业价值**：兼顾通用医疗与产科专科需求，落地性强
3. **性能能效**：本地推理低延迟、量化优化、硬件利用率高
4. **隐私合规**：医疗数据全本地处理，符合医院数据安全要求
5. **智能体架构**：符合赛题鼓励方向，多任务协同、工具化调用
