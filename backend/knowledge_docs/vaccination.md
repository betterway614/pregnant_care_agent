# 孕期疫苗接种指南

## 孕期可接种的疫苗

**流感灭活疫苗：** 强烈推荐孕期接种，可在孕早、中、晚期任何阶段接种。孕妇感染流感后重症和住院风险显著增高，接种灭活流感疫苗既保护母亲也保护新生儿（通过胎盘抗体传递）。每年流感季前接种一次。

**百白破疫苗（Tdap）：** 建议每次怀孕在孕27-36周接种，最好在孕早期（27-28周）接种。主要目的是让母体产生百日咳抗体，通过胎盘传递给胎儿，保护出生后尚未完成疫苗接种的新生儿免受百日咳感染。

**新冠疫苗：** 根据最新指南，孕期可接种经批准的新冠疫苗（mRNA疫苗或灭活疫苗）。感染新冠后孕妇重症风险增高，接种疫苗可显著降低重症和住院风险。建议在孕期任何阶段均可接种，优先推荐mRNA疫苗。

## 禁止接种的疫苗（减毒活疫苗）

以下疫苗因含有活病毒成分，孕期禁用，接种后应避孕至少1个月（部分疫苗需3个月）：

- **麻疹-腮腺炎-风疹疫苗（MMR）：** 接种后避孕3个月
- **水痘疫苗：** 接种后避孕1个月
- **黄热病疫苗：** 除非暴露风险极高，否则孕期禁用
- **卡介苗（BCG）**
- **带状疱疹疫苗**
- **口服脊髓灰质炎疫苗（OPV）**
- **口服伤寒疫苗**

## 接种建议

- 孕前检查时评估疫苗接种史，未完成的疫苗在孕前补种
- 若孕期暴露于特定传染病，应及时咨询医生评估是否需要紧急接种
- 不确定某种疫苗是否安全时，务必先咨询产科医生或疾控部门
- 灭活疫苗和类毒素疫苗总体安全，减毒活疫苗孕期禁用
- 哺乳期接种上述孕期可用疫苗均安全

## 注意事项

- 接种后观察30分钟，注意有无过敏反应
- 接种部位红肿、低热属正常反应，通常1-2天自行消退
- 持续高热（超过38.5摄氏度）、严重过敏反应需及时就医
- 保留接种记录，便于产后补种和新生儿免疫规划参考
